# Employee Leave Management System

A web-based Employee Leave Management System built using **Python and Django** to manage employee records and leave requests.

## Features

- Employee management
- Add, update, view, and delete employee records
- Apply for leave
- Approve and reject leave requests
- Track leave status
- Django Admin for data management
- Responsive user interface using Bootstrap

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap

## Project Objective

The objective of this project is to develop a simple web-based system that digitizes employee leave management and provides an efficient way to manage employee records and leave workflows.

## How to Run

```bash
git clone <your-repository-url>
cd employee-leave-management-django

python -m venv venv
venv\Scripts\activate

pip install django

python manage.py migrate
python manage.py runserver
```

Open the application in your browser:

```text
http://127.0.0.1:8000/
```
